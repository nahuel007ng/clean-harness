# Mobile

- Inspecciona ciclo de vida, navegación, persistencia local y manejo de red antes de editar.
- Considera estados offline, reanudación, permisos, teclado, accesibilidad y tamaños de pantalla.
- Reutiliza patrones nativos y componentes existentes.
- Evita asumir que una API o sensor está disponible, sincronizado o calibrado.
- Ejecuta tests y una comprobación en emulador o dispositivo si el proyecto la dispone.
- Si necesitas capacidad extendida (ej. Compose, CameraX, QA con dispositivo), propón la skill externa con fuente exacta y espera aprobación.
