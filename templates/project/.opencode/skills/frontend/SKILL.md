# Frontend

- Identifica el stack, sistema de componentes y convenciones existentes antes de editar.
- Reutiliza componentes, tokens y patrones ya presentes.
- Verifica estados de carga, vacío, error, teclado, foco, contraste y responsive cuando apliquen.
- Mantén la semántica HTML y evita introducir JavaScript para capacidades nativas de la plataforma.
- Ejecuta tests, lint y una comprobación visual o E2E si el proyecto las dispone.
